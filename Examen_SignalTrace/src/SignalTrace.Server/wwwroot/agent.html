Detenido
Este agente funciona con la pantalla encendida y la pestaña visible. Con la pantalla bloqueada el navegador detiene los sensores y los temporizadores: la telemetría queda en pausa y el dashboard muestra el hueco. Para telemetría continua usa la app Android.
