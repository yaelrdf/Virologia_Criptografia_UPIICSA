# Virologia_Criptografia_UPIICSA

Proyectos de la materia Virología y Criptografía (UPIICSA-IPN, grupo 6NV68).

- [`Examen_Prisma/`](Examen_Prisma/README.md): 2.º parcial, «César + esteganografía + algoritmo propio». ABCO: «César matricial» (Hill 2×2 mod 256 + César dinámico por LCG + encadenamiento XOR) oculto en PNG con recorrido Fisher–Yates y HMAC; 2FA opcional con imagen-llave. API ASP.NET Core 10 + SQLite, cliente web y app Android (Kotlin).
- [`Examen_SignalTrace/`](Examen_SignalTrace/README.md): 2.º parcial, «Inventar un algoritmo de encriptación». Sistema de rastreo de señales y sensores con telemetría cifrada: Yael Crypto March1 (algoritmo propio) + AES-256-GCM, ECDH/HKDF, ECDSA, PBKDF2, HMAC y ChaCha20. Servidor .NET 10, cliente web/PWA, app Android (Kotlin) y simulador.
