# Virologia_Criptografia_UPIICSA

Proyectos de la materia Virología y Criptografía (UPIICSA-IPN, grupo 6NV68).

- [`Examen_SignalTrace/`](Examen_SignalTrace/README.md): 2.º parcial, «Inventar un algoritmo de encriptación». Sistema de rastreo de señales con telemetría cifrada: SigMix (algoritmo propio) + AES-256-GCM, ECDH/HKDF, ECDSA, PBKDF2, HMAC y ChaCha20. Servidor .NET 10, cliente web/PWA, app Android (Kotlin) y simulador.
